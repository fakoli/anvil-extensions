# Anvil Extensions 0.10.0

This release adds `pi-observations`, an optional Pi extension for bounded PNG observation mediation. Its entrypoint is registered in the bundle but remains inert until an empty fresh Pi session explicitly uses `--observation`; it does not change the selected primary model or activate a provider by itself.

The extension resolves one exact registered image-capable provider/model from trusted user-agent policy, validates canonical 8-bit non-interlaced RGB/RGBA PNGs, and sends one image plus a bounded question through Pi's native registered client. The primary receives only bounded text envelopes. It accepts at most 64 source lifetimes including expired tombstones, 256 MiB active bytes, one hour of retention, 32 attempts, 120 seconds cumulative reservation, and 30 seconds per call. It persists metadata, receipts, tombstones, and a ledger in a private user-agent directory, not a second raw-image store. It cancels compaction, fork, and tree operations while enabled; use a new session without `--observation` to stop mediation safely.

Release verification requires the Node 24 offline matrix. An isolated installed-Pi 0.85.1 loopback fixture passed user and tool image mediation, malformed/failure/cancellation/session-budget/fixture-clock-expiry boundaries, primary-media exclusion, original-transcript preservation, clean resume, and cache reuse. A controlled live slice used an explicit registered `llm.secondary` vision model and `llm.primary` primary model with a 128×64 red-left/blue-right PNG (`sha256: 12bdfde7f3c89e2135990a79f859455ed472e55e2a9696d1d532689702279421`): the inspector received one PNG, one explicit question, and a 1,024-token output cap; the primary received no media, originals were unchanged, and both structured facts and the primary answer identified the layout. That is a bounded integration observation, not model qualification, a service change, or authorization to install/activate it on a normal Pi profile.

No migration is required: existing unmarked sessions remain unaffected. Roll back an installed bundle pin to `anvil-v0.9.2` only after closing any marked observation session; preserve Pi sessions and user-agent state. Installation and activation remain separate, reviewed actions. Trusted configuration and the safe disable path are in [the package README](../../packages/pi-observations/README.md).
